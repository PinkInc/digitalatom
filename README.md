# Digital Atom Website

Static responsive website with:
- Home, Services, Projects and About Us pages
- Digital Atom logo and favicon
- Responsive coffee/chocolate theme
- Telegram CTA
- Floating social popup
- Sample client reviews
- Client-side enquiry form that opens an email draft
- Basic Apache security headers via `.htaccess`

## Important
The contact form is intentionally static and does not store submissions. For production, replace the `mailto:` flow with your own HTTPS backend or a reputable form service and perform server-side validation/rate limiting.

Replace the sample:
- phone number
- email
- Telegram username
- Instagram username
- WhatsApp number
- YouTube handle
- sample project/review content

The Telegram CTA currently uses Telegram's share endpoint because no specific Telegram chat username was supplied.
